# 深大健身房自动捡漏器

基于 Python + Tkinter 的深圳大学体育场馆预约辅助工具。程序可以自动获取网页登录 Cookie，拉取健身房时段状态，并在选中时段后持续轮询捡漏；预约成功后会打开“我的预约”页面，由你手动完成支付确认。

## 功能

- 自动打开专用浏览器获取 `ehall.szu.edu.cn` Cookie
- 可视化查看指定日期的健身房时段状态
- 点击时段后后台持续尝试预约
- 支持随时停止当前捡漏任务
- 预约成功后自动打开“我的预约”网页，手动支付
- 运行日志实时显示接口返回结果

## 环境

- Python 3.8+
- Windows 下推荐使用 Microsoft Edge
- 使用时请连接校园网，或确保当前网络能访问深大办事大厅

## 安装

```bash
git clone https://github.com/Georgeupup/szu_gym_helper.git
cd szu_gym_helper
pip install -r requirements.txt
```

依赖包括：

```txt
requests
playwright==1.40.0
```

程序会优先调用系统已安装的 Edge 或 Chrome，因此通常不需要额外执行 `playwright install`。

## 使用
### 方法一：
Releases页面直接下载.exe文件打开运行

### 方法二：
```bash
python szu_gym_helper.py
```

1. 点击 `自动获取`。
2. 在弹出的浏览器窗口中登录深大网上办事大厅，并进入体育场馆预约页面。
3. 程序获取到 Cookie 后会自动填入输入框。
4. 填写与当前登录账号一致的学号/工号和姓名。
5. 选择预约日期，点击 `拉取场馆状态`。
6. 点击目标时段开始捡漏。
7. 抢到后程序会自动打开“我的预约”页面，请在网页中手动完成支付。

Cookie 有有效期。如果提示 Cookie 失效，重新点击 `自动获取` 即可。每次自动获取都会清除专用浏览器中的旧登录态，并要求重新登录，防止切换账号时误用上一个账号的 Cookie。
切换登录账号时，也必须同步修改“预约人信息”；系统会校验预约人与 Cookie 对应的登录人是否一致。

## 手动 Cookie 备用

如果自动获取失败，也可以手动把浏览器请求头里的 Cookie 粘贴到输入框中，再点击 `拉取场馆状态`。不要把自己的 Cookie 提交到仓库或分享给他人。

## 注意事项

- 本工具仅供学习交流和个人合理使用。
- 程序保留了请求间隔，请勿移除限速或进行高频请求。
- 预约和支付结果以学校系统页面为准。
- `.playwright_profile/` 会保存专用浏览器登录态，已加入 `.gitignore`，请不要上传。
